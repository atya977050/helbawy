# أريد إنشاء برنامج استشارات قانونية أون لاين.

أول شاشة:
- شاشة تسجيل دخول للمستخدم برقم التليفون وكلمة المرور.
- بعد الدخول يظهر اسم المستخدم وبياناته.
- المستخدم يدخل إلى قاعة الاستشارة الخاصة به.

قاعة الاستشارة:
- المستخدم يجد المحامي منتظرًا داخل القاعة.
- اتصال صوت وصورة مباشر بين الموكل والمحامي.
- عرض كاميرا الموكل وكاميرا المحامي جنب بعض أفقيًا، وليس واحدة تحت الأخرى.
- أزرار تشغيل وإيقاف الكاميرا والمايك.
- إمكانية إنهاء المكالمة والعودة للقاعة.

الشات داخل قاعة الاستشارة:
- شات خاص بين الموكل والمحامي.
- إرسال واستقبال الرسائل بشكل مباشر.
- إمكانية إرفاق جميع أنواع المستندات والملفات، مثل:
  PDF
  Word
  صور
  ملفات نصية
  مستندات أخرى
- عرض الملفات المرسلة داخل المحادثة مع إمكانية فتحها أو تنزيلها.
- أدوات الشات تكون في شريط أدوات واضح أسفل منطقة المحادثة، مثل:
  📎 إرفاق ملف
  📷 إرسال صورة
  🎙️ تسجيل صوت
  📹 فيديو
  وغيرها من الأدوات اللازمة للمحادثة القانونية.

ردود المحامي:
عند ظهور أي رد من المحامي، تظهر أسفل الرد ثلاثة أزرار واضحة:
- 📋 نسخ
- 📤 تصدير
- 🖨️ طباعة

زر النسخ:
ينسخ نص رد المحامي إلى الحافظة.

زر التصدير:
يسمح بتصدير الرد أو المحادثة بصيغة مناسبة مثل PDF أو ملف نصي.

زر الطباعة:
يفتح إعدادات الطباعة لطباعة رد المحامي أو محتوى الاستشارة.

أريد البرنامج بتصميم احترافي مناسب لمكتب محاماة واستشارات قانونية، وواجهة عربية RTL ومتجاوبة مع الهاتف.

مهم جدًا:
قبل تنفيذ البرنامج فعليًا، اعرض لي أولًا معاينة مرئية للشاشات المقترحة، خصوصًا:
1. شاشة تسجيل الدخول.
2. شاشة القاعة.
3. شاشة الاستشارة بالصوت والصورة.
4. شاشة الشات.
5. شكل رد المحامي وأزرار النسخ والتصدير والطباعة.
6. شكل أدوات الشات أسفل المحادثة.

أريد أن أستطيع اختيار:
نعم، اعتماد الشاشة
لا، حذفها
تعديل الشاشة

وjلا تبدأ إنشاء البرنامج إلا بعد اعتمادي لتنسيق الشاشات.

تم إنشاء هذا المشروع بواسطة عبقرينو Studio.

## البنية

- public — واجهة البرنامج
- server — تشغيل المشروع
- routes — مسارات التطبيق
- services — الخدمات والمنطق
- database — طبقة البيانات
- uploads — الملفات المرفوعة
- .abqaryno-requirements.json — المتطلبات والشاشات المعتمدة

## التشغيل

python server/server.py
