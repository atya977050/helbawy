# أريد من عبقرينو إنشاء برنامج عبارة عن منصة بث جماعي مباشر وتواصل اجتماعي، شبيهة في فكرتها العامة بمنصات البث المباشر الجماعي.

أريد أن تبدأ المنصة بحسابات للمستخدمين وتسجيل الدخول، مع ملف شخصي لكل مستخدم، وحالة المستخدم متصل أو غير متصل.

أريد أن يستطيع المستخدم إنشاء غرفة بث مباشر، والدخول إلى غرف المستخدمين الآخرين، مع وجود صاحب للغرفة وصلاحيات خاصة له وللمشرفين.

داخل غرفة البث أريد:

- بث فيديو مباشر بالكاميرا.
- تشغيل وإيقاف الميكروفون.
- بث صوت وفيديو جماعي لعدة مستخدمين.
- نظام مقاعد داخل الغرفة.
- يستطيع المستخدم طلب الجلوس على مقعد.
- يستطيع صاحب الغرفة قبول أو رفض طلب الجلوس.
- يستطيع صاحب الغرفة أو المشرف إدارة المقاعد والمشاركين.
- كتم صوت مستخدم.
- إزالة مستخدم من الغرفة.
- دعوة مستخدمين إلى الغرفة.
- معرفة المشاركين الموجودين حاليًا داخل الغرفة.
- إظهار حالة الكاميرا والمايك لكل مشارك حسب حالته.

أريد أيضًا شاتًا مباشرًا داخل الغرفة:

- إرسال واستقبال الرسائل لحظيًا.
- تحديد المستلم باستخدام To.
- إرسال واستقبال المرفقات والملفات.
- إمكانية إرسال الصور والفيديو والصوت.
- إمكانية تسجيل رسالة صوتية.
- إشعارات عند وصول رسالة أو دعوة أو طلب جلوس.

أريد نظام تفاعل داخل الغرفة، مثل التفاعلات والرموز والتعبير عن الإعجاب، مع إمكانية تطويره لاحقًا إلى نظام هدايا أو نقاط إذا كان ذلك مناسبًا.

أريد البحث عن المستخدمين والغرف، وعرض الغرف المباشرة المتاحة، مع معلومات عن الغرفة وعدد الموجودين فيها وحالتها.

أريد أيضًا نظام إشعارات للمستخدم يشمل:

- طلبات الجلوس.
- قبول أو رفض الطلب.
- الدعوات إلى الغرف.
- الرسائل الجديدة.
- الإشعارات الخاصة بالغرفة.

أريد أن تكون هناك صلاحيات واضحة:

1. مالك الغرفة.
2. المشرف.
3. المستخدم العادي.
4. الزائر أو المشاهد.

وأريد من النظام أن يراعي الخصوصية والصلاحيات بحيث لا يستطيع المستخدم العادي تنفيذ وظائف خاصة بالمالك أو المشرف.

أريد واجهة عربية RTL حديثة واحترافية ومتجاوبة مع الهاتف والكمبيوتر، مع الحفاظ على سهولة الاستخدام.

أريد من عبقرينو ألا يبدأ في إنشاء البرنامج مباشرة.

أولًا:

1. افهم فكرة البرنامج.
2. اعرض عليّ ما فهمته.
3. استخرج المتطلبات.
4. اقترح جميع الشاشات المطلوبة.
5. اعرض كل شاشة ووظيفتها.
6. اجعلني أختار لكل متطلب وشاشة: نعم أو لا.
7. اسمح لي بتعديل أو إضافة أو حذف أي متطلب.
8. بعد موافقتي النهائية أنشئ خطة البرنامج.
9. اعرض الخطة عليّ للمراجعة.
10. بعد موافقتي ابدأ إنشاء البرنامج.

وأريد أن تكون كل مرحلة تفاعلية، بحيث لا ينتقل عبقرينو للمرحلة التالية إلا بعد موافقتي أو تعديلي.

لا تفترض أي شاشة أو وظيفة غير ضرورية دون عرضها عليّ، وأريد أن تكون البنية قابلة للتوسع مستقبلًا لإضافة وظائف جديدة للمنصة.

تم إنشاء هذا المشروع بواسطة عبقرينو Studio.

## البنية

- public — واجهة البرنامج
- server — تشغيل المشروع
- routes — مسارات التطبيق
- services — الخدمات والمنطق
- database — طبقة البيانات
- uploads — الملفات المرفوعة
- .abqaryno-requirements.json — المتطلبات والشاشات المعتمدة

## التشغيل

python server/server.py
